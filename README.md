# Vai De Bike

Landing page para uma escola de ciclismo, criada como projeto de demonstração
durante meu início de estudos em programação.

**Acesse o site:** https://erikgomes02.github.io/Vai-De-Bike/


## Sobre o projeto

Este projeto foi desenvolvido como demonstração do meu início de estudos em
programação e oferecido a uma instituição real, o **Bicicletário de Itapuã**.

O site apresenta uma escola de bicicleta onde qualquer pessoa, de qualquer idade,
pode aprender a pedalar, com informações sobre planos, dúvidas frequentes e
um formulário para agendar aulas.

## Funcionalidades

- Menu de navegação com rolagem para cada seção
- Seção de preços com 3 planos (individual, dupla e família)
- Perguntas frequentes
- Formulário de agendamento de aulas
- Layout responsivo (adaptado para celular e computador)

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
